Role × module

Who sees which module

Rendered live from DORUM.roles[].navItems — the same data that builds the app sidebar. A dot means the module is in that role's navigation; the plan's §3.1 refines this into full / edit-own / view-scoped permissions.

Tenant model

Platform → tenant → office → roles → users

Roles are data, not code: a tenant can rename “Broker” to “Asesor” or add a “Marketing Lead” without a release. Customers and vendors are users too, scoped to the deals they take part in.
